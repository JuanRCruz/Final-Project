# Galaxy Explorer

## Project Option
Responsive Website

## Project Description
Galaxy Explorer is a responsive educational website that allows users to learn about planets in our solar system. The website combines interesting information, images, and interactive features to create an enjoyable learning experience. Users can browse through planet cards, reveal hidden facts, and test their knowledge with a short quiz.

---

## Theme Interpretation

This project is based on the theme of **Space**. It presents information about the planets in our solar system using a modern space-inspired design with dark colors, glowing buttons, and interactive elements that encourage exploration.

---

## Intended User

- Middle school students
- High school students
- Anyone interested in astronomy
- People who enjoy interactive educational websites

---

## User Goal

The goal is to explore the planets, learn interesting facts about space, and complete the quiz to test what was learned.

---

## Main Features

- Responsive single-page website
- Space-themed design
- Planet gallery
- Hidden space facts
- Interactive quiz
- Smooth scrolling navigation
- Hover animations
- Mobile-friendly layout

---

## JavaScript Features

The website includes several JavaScript interactions:

- Show and hide additional planet facts
- Interactive quiz with correct/incorrect feedback
- Navigation link highlighting
- Animated planet cards
- Welcome message
- Animated call-to-action button

---

## Responsive Design

The website uses CSS Grid and Flexbox to automatically adjust the layout for different screen sizes. A media query changes the navigation menu, spacing, text sizes, and image sizes to improve the experience on tablets and phones.

---

## User Testing

User testing showed that visitors liked the overall space theme and found the navigation easy to use. Feedback suggested making the quiz button more noticeable, improving the mobile layout, and adding clearer quiz feedback.

---

## Revisions

The following improvements were made after testing:

- Improved the mobile layout using media queries.
- Increased button visibility.
- Added clearer quiz feedback.
- Improved spacing between sections.
- Enhanced hover effects for better interaction.
